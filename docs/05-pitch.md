# Pitch

## FinanIA — Assistente Financeira com Inteligência Artificial

A FinanIA é um protótipo de assistente virtual desenvolvido com Inteligência Artificial Generativa para auxiliar pessoas que estão começando a aprender sobre finanças pessoais.

Muitas pessoas têm dificuldade para entender conceitos financeiros, organizar seus gastos e interpretar informações relacionadas à própria vida financeira. Pensando nesse problema, a FinanIA foi projetada para oferecer uma experiência simples, acessível e educativa.

A solução permite consultar informações financeiras simuladas, analisar receitas e despesas, compreender conceitos e produtos financeiros e realizar simulações simples.

A FinanIA utiliza uma base de conhecimento estruturada com dados simulados de perfil financeiro, transações, produtos financeiros e histórico de atendimento. Essas informações são utilizadas para contextualizar as respostas do modelo de linguagem.

Um dos principais diferenciais do projeto é a preocupação com segurança e confiabilidade. A FinanIA não deve inventar informações quando os dados não estiverem disponíveis. Quando não possui dados suficientes, o agente informa sua limitação.

Além disso, o protótipo não realiza operações bancárias, não acessa contas reais e não apresenta simulações como garantias de resultados futuros.

A arquitetura combina uma interface interativa, uma aplicação em Python, uma base de conhecimento, um modelo de linguagem e regras de validação das respostas.

O projeto também possui métricas para avaliar precisão, segurança, coerência com o perfil, adequação ao escopo e clareza das respostas.

A FinanIA demonstra como a Inteligência Artificial Generativa pode ser aplicada à educação financeira de maneira contextualizada, mantendo transparência sobre os dados utilizados e as limitações do sistema.

## Roteiro para Apresentação

### 1. Problema — aproximadamente 30 segundos

"Muitas pessoas têm dificuldade para compreender conceitos financeiros e organizar seus gastos. Mesmo quando encontram informações na internet, elas podem ser complexas ou pouco contextualizadas."

### 2. Solução — aproximadamente 40 segundos

"Para solucionar esse problema, desenvolvi a FinanIA, uma assistente virtual baseada em Inteligência Artificial Generativa que ajuda o usuário a entender conceitos financeiros, analisar gastos e realizar simulações simples."

### 3. Funcionamento — aproximadamente 50 segundos

"A FinanIA utiliza uma base de conhecimento com dados financeiros simulados. A aplicação consulta essas informações, organiza o contexto necessário e utiliza um modelo de linguagem para gerar a resposta. A aplicação também possui regras para evitar que o agente invente informações."

### 4. Segurança — aproximadamente 30 segundos

"Um ponto importante do projeto é a segurança. A FinanIA não acessa contas bancárias reais, não realiza transações e não deve inventar dados quando não possui informações suficientes. As simulações são apresentadas como simulações e não como garantias de resultados."

### 5. Demonstração — aproximadamente 20 segundos

"Durante a demonstração, é possível perguntar sobre gastos, consultar informações da base e realizar uma simulação. Também podemos testar situações em que não existem dados suficientes e verificar como o agente reage."

### 6. Encerramento — aproximadamente 10 segundos

"A FinanIA mostra como a Inteligência Artificial Generativa pode ser utilizada para tornar a educação financeira mais acessível, combinando interação em linguagem natural, dados estruturados e mecanismos de segurança."
